# LUDB Record 157

Ein einzelner Record (10 s, 12 Kanäle, 500 Hz, gesunde Sinusrhythmus-Aufnahme,
28-jähriger Mann, normale elektrische Herzachse, keine Auffälligkeiten) aus
der [Lobachevsky University Electrocardiography Database (LUDB)](https://physionet.org/content/ludb/1.0.1/),
PhysioNet, ausschließlich für [`00_showcase.ipynb`](../notebooks/00_showcase.ipynb).

Nur `157.dat` + `157.hea` (Rohsignal) — keine Annotationsdateien, da das
Showcase-Notebook die eigene `vcgsuite`-Delineation zeigt, nicht die
LUDB-Ground-Truth.
